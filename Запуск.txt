Как запускать ShopSee
1. Бэкенд (FastAPI + YOLO)
В PowerShell:

cd c:\Users\nebedl\Desktop\shopsee\backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
Проверка: в браузере открой http://127.0.0.1:8000/api/health — должно быть "status":"ok" и желательно "detector_ready":true.
Первый раз модель yolov8n.pt может скачаться сама (нужен интернет).
2. Фронтенд (Next.js)
В другом окне терминала:


cd c:\Users\nebedl\Desktop\shopsee\frontend
npm install
npm run dev
